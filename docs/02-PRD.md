# PRD：ExpertBrain 企业行业专家系统

版本：V1.0

## 1. 产品定位

ExpertBrain 是企业级行业专家系统，用于管理企业行业知识、业务经验、客户案例和业务规则，并基于 RAG 和规则引擎为业务人员提供问答、客户分析和服务方案生成能力。

产品不是简单的 AI 聊天工具，而是：

- 知识资产管理系统
- 行业专家问答系统
- 业务规则管理系统
- 客户画像分析系统
- 服务方案生成系统

## 2. 用户角色

### 2.1 超级管理员

负责系统配置、用户管理、角色权限、知识库配置、AI 配置。

### 2.2 知识管理员

负责知识文档、分类、标签、版本、审核、发布、失效管理。

### 2.3 业务人员

负责查询知识、录入客户、生成客户分析和服务方案。

### 2.4 管理层

查看知识贡献、使用统计、客户方案、业务效果。

## 3. V1 功能范围

### 3.1 知识中心

支持知识库、分类、标签、文档、在线经验、平台资料、法规政策、案例复盘的统一管理。

文档类型：

- PDF
- Word
- Excel
- Markdown
- TXT
- HTML/URL
- 图片 OCR（V1 可先预留接口）

文档状态：

- draft：草稿
- pending：待审核
- published：已发布
- expired：已失效
- archived：已归档

### 3.2 RAG 问答中心

业务人员可以自然语言提问。

系统需要返回：

- 直接回答
- 引用来源
- 引用片段
- 置信提示
- 不确定说明

要求：没有检索依据时，不允许编造确定答案。

### 3.3 客户中心

录入客户基础信息：

- 企业名称
- 统一社会信用代码
- 省市区
- 经营范围
- 主营产品
- 资质情况
- 目标平台
- 当前状态
- 备注

系统自动生成客户标签。

### 3.4 规则中心

管理业务确定性规则，例如：

- 经营范围包含“办公用品” → 推荐京东慧采、青慧采。
- 经营范围包含“医疗器械” → 需要检查医疗器械经营许可证。
- 目标平台为京东慧采 → 需要检查营业执照、品牌/授权、商品资料。

规则支持：

- 条件 JSON
- 结果 JSON
- 优先级
- 启用/停用
- 规则命中日志

### 3.5 服务方案中心

业务人员选择客户并填写服务目标后，系统生成服务方案。

方案包括：

- 客户基本判断
- 推荐平台
- 推荐服务内容
- 推荐商品方向
- 办理流程
- 所需资料
- 风险提示
- 参考案例
- 法规/平台依据
- 预计周期

### 3.6 案例中心

管理成功案例、失败案例、复盘记录。

案例字段：

- 标题
- 客户行业
- 平台
- 客户情况
- 服务过程
- 结果
- 经验总结
- 风险点
- 关联知识

## 4. 非功能需求

### 4.1 权限

必须支持 RBAC。不同角色看到的菜单和操作不同。

### 4.2 审计

重要写操作必须记录审计日志：谁在什么时间修改了什么。

### 4.3 引用

AI 问答和方案生成必须返回引用来源结构。

### 4.4 性能

- 普通列表接口：≤ 1 秒。
- RAG 问答：≤ 10 秒。
- 方案生成：≤ 30 秒。

### 4.5 可维护性

模型、Embedding、LLM Provider 必须可配置，不与业务代码强耦合。

## 5. V1 不做

- 不自动操作第三方采购平台。
- 不做浏览器自动化。
- 不做模型微调。
- 不做复杂多 Agent 协作。
- 不对外开放客户自助门户。
- 不做移动 App。

## 6. 验收标准

V1 验收以内部业务可用为准：

1. 可以创建知识库、分类、标签、文档。
2. 可以上传或录入文档并完成 chunk/embedding。
3. 可以对知识库提问并返回引用。
4. 可以录入客户并生成客户标签。
5. 可以配置规则并在客户分析中命中规则。
6. 可以生成服务方案并保存。
7. 管理员可以查看基础统计。
