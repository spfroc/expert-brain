# 开发路线图

## Phase 0：项目初始化

目标：建立开发基础。

任务：

- Laravel 项目初始化
- Vue3 项目初始化
- FastAPI 项目初始化
- Docker Compose
- PostgreSQL + pgvector
- Redis
- 基础 CI

交付物：可本地启动的三服务架构。

## Phase 1：认证与权限

目标：完成后台登录和 RBAC。

任务：

- 用户登录/退出
- 当前用户信息
- 角色权限
- 菜单权限
- 审计日志基础

交付物：可登录后台，有权限控制。

## Phase 2：知识管理

目标：完成知识库基础管理。

任务：

- 知识库 CRUD
- 分类树 CRUD
- 标签 CRUD
- 文档 CRUD
- 文件上传
- 文档状态流转

交付物：业务人员可以录入和管理知识。

## Phase 3：文档解析与向量化

目标：知识可被检索。

任务：

- FastAPI 文档解析接口
- chunk 切分
- BGE-M3 embedding
- 写入 pgvector
- reindex 机制

交付物：文档可以转为 chunks 并生成 embedding。

## Phase 4：RAG 问答

目标：完成知识库问答。

任务：

- hybrid search
- Prompt 构造
- LLM Provider
- 引用返回
- 会话保存
- 前端聊天界面

交付物：用户可以问答并查看引用。

## Phase 5：客户与规则

目标：客户分析基础可用。

任务：

- 客户 CRUD
- 客户标签
- 规则 CRUD
- 规则测试
- 规则命中日志
- 客户分析接口

交付物：录入客户后能生成平台和风险初步判断。

## Phase 6：服务方案生成

目标：生成可用服务方案。

任务：

- 方案生成接口
- 规则 + 检索 + 案例 + LLM 编排
- 方案保存
- 方案详情
- 方案人工编辑

交付物：针对客户生成入驻/发品/平台建议方案。

## Phase 7：案例与统计

目标：形成闭环。

任务：

- 案例中心
- 知识引用统计
- 问答统计
- 方案生成统计
- 知识贡献统计

交付物：管理层可以看到知识资产使用情况。

## 推荐时间

两名开发情况下：

- Phase 0-1：2 周
- Phase 2：2 周
- Phase 3：2 周
- Phase 4：2 周
- Phase 5：2 周
- Phase 6：2 周
- Phase 7：1-2 周

总周期：约 3 个月形成 V1。
